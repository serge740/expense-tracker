# Web app changes that are not on the Expo app yet

The web app (`frontend/`, built into `backend/web`) moved ahead of the phone app (`expo_app/`). This file lists every
difference so the Expo app can be brought up to date later, one row at a time. **Keep it current: add a row whenever the
web gets something Expo does not have, and tick the row when Expo catches up.**

Legend: ⬜ Expo does not have it · ✅ Expo has it · ➖ nothing to do on Expo

## 4. How to use this file

1. When you build something on the web only, add a row (what, files, what Expo needs, ⬜).
2. When Expo catches up, change ⬜ to ✅ and note the commit.
3. Backend rows (section 1) need the migration run and the backend deployed before Expo can use them.
